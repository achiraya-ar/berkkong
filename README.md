# BerkKong v1.8.51

**BerkKong** คือโปรแกรมเดสก์ท็อปสำหรับบันทึก **การเบิกพัสดุสำนักงาน** และ **เวชภัณฑ์ที่มิใช่ยา** ของหน่วยงานในโรงพยาบาล ออกแบบตามโลโก้ BerkKong ธีม Mickey Mouse โทนแดง–ดำ–เหลือง

## แนวคิดของโปรแกรม

BerkKong **ไม่ได้เป็นระบบคลังสินค้า** และ **ไม่คำนวณจำนวนคงเหลือ** ระบบทำหน้าที่เพียง:

- บันทึกว่าเบิกอะไร
- เบิกจำนวนเท่าไร ตามหน่วยนับที่ตั้งค่าไว้
- เบิกเมื่อไร
- พิมพ์ใบเบิก 2 รูปแบบเพื่อลงนามและเก็บหลักฐาน

## ฟีเจอร์

- หน้าเข้าสู่ระบบแบบมาสคอตโลโก้ BerkKong ขนาดใหญ่ ไม่มีฟอร์ม โน๊ตบุ๊คในโลโก้ขยับลอยขึ้นลง พร้อมบรรยากาศการ์ตูนมิกกี้ (ลายมิกกี้ ดาวประกาย กลุ่มดาวการ์ตูนที่มุมขวาล่าง) และคลิกที่มาสคอตเพื่อเข้าสู่ระบบ
- หน้าแรกเหลือเพียงตัวเลือก 2 ประเภทใบเบิก เพื่อให้เห็นชัดเจน
- หน้าทำงานแบบ document-first คล้าย SnapHerb: แถบคำสั่งด้านบน + เอกสาร A4 ขนาดใหญ่
- หน้าทำงานแยกโทนสีชัดเจน และไม่มีการสลับประเภทในหน้าเบิก (ต้องกลับไปเลือกที่หน้าแรก)
- ป๊อปอัปเพิ่มรายการใหม่เปลี่ยนสีตามหมวดที่เลือก
- **รายการของเบิก** รวมอยู่ในหน้าตั้งค่า พร้อมสลับหมวดรายการพัสดุ / รายการเวชภัณฑ์ และเพิ่มรายการตามหมวดที่เลือก
  - ใบเบิกพัสดุ — โทนเหลือง/ทอง
  - ใบเบิกเวชภัณฑ์ที่มิใช่ยา — โทนชมพู/แดง
- เพิ่มรายการพัสดุ/เวชภัณฑ์พร้อมกำหนดหน่วยนับของแต่ละรายการ
- รหัสรายการเรียงต่อเนื่องอัตโนมัติเมื่อลบ และมีปุ่ม “รันเลขใหม่” สำหรับปิดช่องว่าง
- เพิ่มรายการชั่วคราวในป๊อปอัปเลือกของได้ โดยใช้เฉพาะใบเบิกนั้นและไม่บันทึกเข้าในการตั้งค่า
- กด **เลือกรายการ** เปิดหน้าต่างเลือกของ คลิกรายการเพื่อเพิ่ม 1 หน่วย แล้วปรับจำนวนได้ทันที
- ไม่มีสต็อก ไม่มีการตัดจำนวน ไม่มีขั้นตอนจ่ายของ
- **บันทึกฉบับร่าง** เก็บไว้แก้ไขภายหลัง
- **บันทึกส่งเบิกของ** บันทึกสถานะส่งเบิกและเปิดหน้าต่างพิมพ์ 2 ใบ
- เอกสาร 2 รูปแบบ
  - **ใบเบิกของระบบ** — เอกสารแบรนด์ BerkKong
    - ลงชื่อ ผู้เบิก ผู้ตรวจรับ และ หัวหน้างาน
    - แสดงชื่อในวงเล็บและวันที่
  - **ใบเบิกมาตรฐาน** — รูปแบบราชการขาวดำตามฟอร์มตัวอย่าง
    - ลงชื่อ ผู้เบิก ผู้รับ ผู้สั่งจ่าย ผู้จ่าย
    - ช่องคงเหลือและช่องจ่ายเว้นไว้ให้เจ้าหน้าที่เขียนด้วยมือ
- ตั้งค่าผู้ลงนาม **แยกตามประเภทใบเบิก** ทั้ง 2 ประเภท
  - ผู้เบิก
  - หัวหน้างาน (ใบเบิกของระบบ)
  - ผู้รับ
  - ผู้สั่งจ่าย
  - ผู้จ่าย
- ตั้งชื่องาน/หน่วยงานเริ่มต้นแยกตามประเภท
- แยกเลขรันของใบเบิกแต่ละประเภท พร้อมคำนำหน้า เช่น `OFF-2569-0001` และ `MED-2569-0001`
- หน้าตั้งค่าแบบ tab คล้าย SnapHerb
- ประวัติการเบิก ค้นหา เปิดดู พิมพ์ซ้ำ ยกเลิก และลบประวัติที่ไม่ต้องการเก็บ
- สำรอง/นำเข้าการตั้งค่าและรายการของเบิกแบบเลือกส่วนได้ JSON
- รองรับ A4 หลายหน้า (20 รายการต่อหน้า) และบันทึกเป็น PDF ผ่านหน้าต่างพิมพ์

## การใช้งาน

1. คลิกที่มาสคอตบนหน้าแรกเพื่อเข้าสู่ระบบ
2. ที่หน้าแรก เลือก **ใบเบิกพัสดุ** หรือ **ใบเบิกเวชภัณฑ์ที่มิใช่ยา**
3. ตรวจงาน/หน่วยงาน และวันที่ต้องการใช้
4. กด **เลือกรายการ** แล้วคลิกรายการเพื่อเพิ่ม จากนั้นปรับจำนวนในหน้าต่างเลือก
5. ตรวจตัวอย่างเอกสารทั้ง 2 รูปแบบ
6. กด **บันทึกฉบับร่าง** หรือ **บันทึกส่งเบิกของ**
7. เมื่อส่งเบิก ในหน้าต่างพิมพ์เลือกเครื่องพิมพ์ หรือเลือกบันทึกเป็น PDF

### การตั้งค่า

- **ข้อมูลโรงพยาบาล** — ชื่อโรงพยาบาล ข้อความ “ถึง...” และชื่อเจ้าหน้าที่ในหัวตารางหมายเหตุ
- **ใบเบิกพัสดุ / ใบเบิกเวชภัณฑ์** — แท็บแยกตามประเภท ประกอบด้วย
  - งาน/หน่วยงาน
  - ผู้เบิก
  - หัวหน้างาน
  - ผู้รับ
  - ผู้สั่งจ่าย
  - ผู้จ่าย
  - เลขที่ใบเบิก (คำนำหน้า ปี พ.ศ. และลำดับแยกกัน)
- **รายการของเบิก** — จัดการรายการและหน่วยนับ แยกหมวดพัสดุ/เวชภัณฑ์ (อยู่ในหน้าตั้งค่า)
- **สำรองข้อมูล** — ส่งออก/นำเข้าการตั้งค่าและรายการของเบิก JSON แบบเลือกได้เป็นรายส่วน (ข้อมูลโรงพยาบาล / ใบเบิกพัสดุ / ใบเบิกเวชภัณฑ์ / รายการของเบิก) โดยไม่รวมประวัติการเบิก

### การพิมพ์

- กระดาษ **A4**
- ขนาด **100%**
- ปิดหัว/ท้ายกระดาษของเบราว์เซอร์
- ระบบพิมพ์ทั้ง 2 รูปแบบให้อัตโนมัติ

## การพัฒนา

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด `http://localhost:1420`

### Desktop (Tauri 2)

```bash
npm install
npm run tauri:dev
```

สร้างชุดติดตั้ง:

```bash
npm run tauri:build
```

ไฟล์ติดตั้งจะอยู่ใต้ `src-tauri/target/release/bundle`

## โครงสร้างโปรเจกต์

```
src/
  components/
    documents.tsx       ใบเบิกของระบบ + ใบเบิกมาตรฐาน (A4)
    RequisitionPage.tsx หน้าเลือกและกรอกจำนวน
    ItemsPage.tsx       รายการและหน่วยนับ
    HistoryPage.tsx     ประวัติและพิมพ์ซ้ำ
    SettingsPage.tsx    ตั้งค่าแยกตามประเภท
  lib/                  วันที่ storage และ seed data
  store/                สถานะแอปและ persistence
  styles/               design tokens, หน้าจอ, เอกสาร, print CSS
src-tauri/              Tauri desktop wrapper
public/logo.svg         โลโก้และไอคอน
ตัวอย่าง/                ฟอร์มใบเบิกต้นฉบับ
```

## ข้อมูล

- เก็บใน `localStorage` ภายใต้คีย์ `berkkong.data.v2`
- ข้อมูลเดิมจากเวอร์ชันก่อนจะถูกแปลงให้อัตโนมัติ
- แนะนำให้สำรองข้อมูลเป็น JSON เป็นประจำจากหน้า **ตั้งค่า → สำรองข้อมูล**
- ไม่เชื่อมต่อ HOSxP และไม่ส่งข้อมูลออกเครือข่าย
